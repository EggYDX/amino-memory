# 🧬 氨基酸 · 记忆练习

**都知道它是氨基酸，至于是哪一种……让我再看一眼侧链。**

22 种氨基酸，22 套结构，外加一堆经常记串的缩写。

明明昨天还认识 `Asp`，今天又把它叫成了 `Asn`。至于 `Leu` 和 `Ile`，它们似乎一直在考验我的眼力。

于是有了这个小网站：专门练习氨基酸的结构、中文名称、三字母与单字母缩写。认不出来就多见几次，直到它们不再那么面生。

缩写题需要自己填，不能靠四选一碰运气。大小写默认严格判定，但可以在设置中调整。

中文名称可以选择填空或选择题。如果想同时练三字母和单字母缩写，也没问题。

## 🧠 不只是随机抽题

背了又忘、忘了再背，大概是学习生化时最熟悉的循环之一。

这里准备了几种不同的练习方式：

- **均衡轮换**：22种都要认识，不能厚此薄彼。
- **自适应强化**：答错的多见几面，答对的适当放行。
- **错题强化**：专门照顾那些总是认错的老熟人。
- **间隔复习**：借助 FSRS 安排长期复习，不必每天从头背起。

而且，能从中文名称想起 `Glu`，不代表看到结构就能认出它。不同方向的练习表现会分别记录。

## 🧪 特别关注这些容易认错的家伙

| 组合 | 看哪里？ |
|---|---|
| Leu / Ile | 侧链的分支位置 |
| Asp / Asn | 羧酸根与酰胺的区别 |
| Glu / Gln | 同样容易混淆的末端基团 |
| Ser / Thr | 多出来的甲基 |
| Cys / Sec | 硫与硒的区别 |

除了常见的20种氨基酸，这里还有两位特别嘉宾：

**硒代半胱氨酸（Sec / U）** 和 **吡咯赖氨酸（Pyl / O）**。

总共22种，一个都不能少。

## 📊 记忆留下痕迹

练习记录保存在浏览器中，可以随时查看：

- 哪些氨基酸已经比较熟悉
- 哪些结构总是认错
- 哪种缩写最容易写错
- 每次练习的表现
- 接下来需要复习什么

支持导出和导入 JSON 备份。

**小提醒：** 数据保存在当前浏览器，不会自动跨设备同步。换手机、换电脑或者准备清理浏览器数据前，记得先导出备份。

## 🛠️ 想在本地运行？

项目基于 React、TypeScript 和 Vite 开发，使用 IndexedDB 保存学习记录，`ts-fsrs` 负责长期间隔复习。

需要 Node.js 22.12+ 和 pnpm。

```bash
pnpm install
pnpm dev
```

构建与测试：

```bash
pnpm test
pnpm build
pnpm preview
```

也可以通过 GitHub Actions 部署到 GitHub Pages。
