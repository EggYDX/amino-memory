# 🧬 氨基酸 · 记忆练习

**都知道它是氨基酸，至于是哪一种……让我再看一眼侧链。**

昨天还认识 Asp，今天又把它叫成 Asn。Leu 和 Ile，则一直在考验我的眼力。

这个小网站专门练习22种氨基酸的结构、中文名称、三字母与单字母缩写，包括 Sec / U 和 Pyl / O。

### 🎮 [开始记忆练习](https://eggydx.github.io/amino-memory/)

无需注册，电脑和手机都能练。手机可添加到主屏幕，首次联网完成缓存后可以离线使用。

## 今天想怎么练？

| 玩法 | 任务 |
|---|---|
| 看结构 | 认名称、写缩写 |
| 看名称或缩写 | 换一条方向回忆 |
| 认结构 | 从几张结构图里找到答案 |
| 自定义 | 题目给什么、考什么，自己决定 |
| 图鉴 | 隐藏答案、比较侧链、查看教材重点性质 |
| 错题重练 | 看清上次混在哪里，再做辨析 |

缩写需要自己填写，大小写默认严格判定，可在设置里调整。多目标分别判分：Enter 移到下一项，最后一项 Enter 提交。每次开始前可确认范围、方向和题量；中途退出可以保留进度，也可以结束并查看已做题目的成绩。

答对后可选填回忆感受。选择题靠猜，也可以如实标记；无需每题手动评分。

## 不只是随机抽题

- **自适应强化**：根据具体记忆方向的近期表现与复习状态安排题目，答错后隔几题重测。会留出探索机会，因此22题不一定覆盖22种。
- **均衡轮换**：优先全面覆盖，并兼顾跨场次和不同记忆方向的练习分布。
- **错题强化**：优先练习近期出错的转换方向，连续答对后减少重复。
- **间隔复习**：用 FSRS 安排长期复习；快速重复答对不会反复增加长期稳定性。

能从名称写出 Glu，不代表看到结构就能认出它。不同方向、填空和选择题分别记录。复习目标保持率是模型设置，不是已经测出的个人保持率。

图鉴沿用课程教材的分类，Met 保留在“极性不带电”，并补充整体偏疏水的说明。分类菜单里有五种 pKₐ(R) / pI 教材重点；其他氨基酸也有等电点。“显示内容”可展开名称、缩写和数值的独立开关。这些性质只供图鉴学习。

## 记忆留下痕迹

记录里可以查看首次作答、整题和单目标表现、纠错重测、实际混淆，以及下次复习时间。空训练不会进入历史，提前结束会标记已完成的题量。

学习数据保存在当前浏览器，不会自动跨设备同步。换手机、换电脑或清理浏览器前，在设置中导出 JSON；新设备再导入。更新网页可以沿用同一网址下的记录。

## 本地运行

需要 Node.js 22.12+ 和 pnpm。已构建的下载包可以双击 **启动网页.cmd**。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

```bash
pnpm test
pnpm build
pnpm preview
pnpm exec playwright install chromium
pnpm test:e2e
```

端到端测试使用独立的生产预览。端口冲突时设置 `TEST_PORT` 换一个端口；可额外安装 WebKit，设置 `TEST_WEBKIT=1` 并运行 `pnpm test:e2e --project=webkit` 进行手机 Safari 模拟。
